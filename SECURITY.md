# Security Policy

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, pull requests or
discussions.

Report them privately through GitHub instead: open the repository's
**Security** tab and click **Report a vulnerability**, or go straight to
https://github.com/django-tenants/django-tenants/security/advisories/new.

Please include the affected versions, a description of the issue and steps or
a proof of concept to reproduce it. You will get a reply as soon as the report
has been reviewed. Fixes are released as a new version together with a GitHub
security advisory, and reporters are credited unless they prefer not to be.

## Supported versions

Security fixes are made to the latest release only, currently 4.0.x. Please
upgrade to the latest version before reporting.
